# Проект: Виджет банковских операций

## Описание
Этот проект содержит функции для фильтрации и сортировки данных по банковским операциям клиентов.

## Функционал
В модуле `src/processing.py` реализованы:
* `filter_by_state` — фильтрация операций по статусу (`EXECUTED`, `CANCELED`).
* `sort_by_date` — сортировка операций по дате (от свежих к старым).
