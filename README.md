# \# Проект Банковских Операций (homework10\_1-)

# 

# \## Описание

# Данный проект предназначен для фильтрации и сортировки банковских операций пользователей. 

# Включает в себя функции маскирования карт/счетов и модули для обработки списков транзакций.

# 

# \## Установка

# 1\. Клонируйте репозиторий.

# 2\. Установите зависимости с помощью Poetry:

# &#x20;  ```bash

# &#x20;  poetry install

# &#x20;  ```

# 

# \## Использование модулей

# \### Модуль processing

# Предоставляет функции для обработки списков транзакций:

# \- `filter\_by\_state(data, state)`: Фильтрует транзакции по статусу (например, 'EXECUTED', 'CANCELED').

# \- `sort\_by\_date(data, reverse)`: Сортирует транзакции по дате.

### Модуль generators
Предоставляет инструменты для эффективной обработки больших массивов данных:
- `filter_by_currency(transactions, currency)`: Итератор, фильтрующий транзакции по коду валюты (USD, RUB и т.д.).
- `transaction_descriptions(transactions)`: Итератор, возвращающий текстовое описание для каждой транзакции.
- `card_number_generator(start, end)`: Генератор номеров карт в формате `XXXX XXXX XXXX XXXX` для заданного диапазона чисел.

### Модуль decorators
Содержит декораторы для расширения функционала других модулей:
- `@log(filename=None)`: Декоратор автоматического логирования работы функций. Умеет отслеживать успешные запуски и возникающие исключения вместе с переданными аргументами. Логирует в файл или в консоль.
